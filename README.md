Useful list of skills for various purposes.

## Frontend Development

- [Impeccable](https://github.com/pbakaus/impeccable)
  Design guidance for AI coding agents. 1 skill, 24 commands, live browser
  iteration, and 61 deterministic detector rules for AI-generated frontend design.

```bash
npx skills add https://github.com/pbakaus/impeccable --skill impeccable
```

- [Kowalski Design](https://github.com/emilkowalski/skills)

```bash
npx skills@latest add emilkowalski/skills
```

- [Taste](https://github.com/leonxlnx/taste-skill)
  Portable Agent Skills that upgrade AI-built interfaces: stronger layout, typography,
  motion, and spacing instead of boilerplate-looking UIs.

```bash
npx skills add https://github.com/Leonxlnx/taste-skill
```
