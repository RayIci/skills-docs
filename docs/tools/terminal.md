# Terminal & Agent Orchestration

- [Herdr](https://github.com/herdrdev/herdr)
  Open-source, Rust-based terminal multiplexer for running coding agents such as
  Claude Code and Codex. Keeps sessions alive in the background, shows which panes
  are working, blocked or idle, and lets agents control panes via a CLI and socket API.

  ```bash
  curl -fsSL https://herdr.dev/install.sh | sh
  ```

## Plugins

- [herdr-annotate](https://github.com/plannotator/herdr-annotate)
  Annotate terminal text and review agent replies from inside Herdr. See [Plan Review](plan-review.md).
