# Software Development

General-purpose engineering skills and workflows.

- [Matt Pocock Skills](https://github.com/mattpocock/skills/tree/main)
  Reusable, adaptable agent skills for real software engineering: grilling
  sessions, TDD, debugging and more. Works with Claude Code, Codex and others.

  ```bash
  claude plugin install mattpocock-skills@claude-plugins-official
  ```

- [Pstack Cursor](https://github.com/backnotprop/pstack)
  Standalone mirror of Poteto's Cursor plugin: agent skills and engineering principles,
  centered on a `/poteto-mode` router, for rigorous AI-assisted coding.

  ```bash
  npx skills add backnotprop/pstack
  ```

## Related tools

- [Open Code Review - Alibaba](https://github.com/alibaba/open-code-review)
  AI-powered code review CLI tool.
- [OpenSpec](https://github.com/Fission-AI/openspec)
  Spec-driven development framework: you and your AI assistant agree on requirements
  and plans before any code is written.
- [Plannotator and friends](../tools/plan-review.md)
  Annotation tools for reviewing agent plans and diffs.
